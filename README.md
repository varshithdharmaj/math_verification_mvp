# MVM²: Adaptive Multi-Signal Consensus & Reporting Service

MVM² is a neuro-symbolic framework for verifying mathematical reasoning steps, specifically optimized for handwritten math datasets.

## Features
- **Adaptive Multi-Signal Consensus**: Combines symbolic verification (SymPy), logical consistency, and classifier confidence.
- **Handwritten Math Optimization**: CLAHE enhancement and Gaussian Blur tailored for student notebook photos.
- **Explainable Diagnostic Reports**: Automated hallucination detection and annotated reasoning traces.

## Setup
This space requires the following secrets:
- `GEMINI_API_KEY`: For multi-agent ensemble queries.
- `HF_TOKEN`: For model downloads and management.

## Paper Context
Developed as part of the MVM² project for Explainable AI in Education.
