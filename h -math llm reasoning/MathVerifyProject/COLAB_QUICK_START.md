# 🚀 Colab Quick Start Guide

## Step-by-Step Instructions

### 1. Open Google Colab
Go to: https://colab.research.google.com

### 2. Upload the Notebook
- Click **"Upload"** tab
- Select `MathVerify_Colab.ipynb` from your project folder
- The notebook will open in Colab

### 3. Run All Cells
- Click **"Runtime"** → **"Run all"**
- Or press `Ctrl+F9` (Windows) / `Cmd+F9` (Mac)
- Wait for all cells to complete (takes 2-3 minutes first time)

### 4. Access the Interface
After the last cell runs, you'll see:
- An embedded Gradio interface in the notebook
- A **public URL** (e.g., `https://xxxxx.gradio.live`)
- You can use either one!

## Troubleshooting

**If cells fail:**
1. Click **"Runtime"** → **"Restart runtime"**
2. Click **"Runtime"** → **"Run all"** again

**If dependencies fail:**
- Colab usually handles this automatically
- Check the error message in the cell output
