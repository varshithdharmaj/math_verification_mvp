# Google Colab Setup Guide

## Quick Start

1. **Open the notebook**: `MathVerify_Colab.ipynb`
2. **Upload to Colab**: 
   - Go to https://colab.research.google.com
   - Click "Upload" → Select `MathVerify_Colab.ipynb`
3. **Run all cells**: Click "Runtime" → "Run all"

## What You'll Get

- ✅ Interactive Gradio web interface
- ✅ Public URL (works from anywhere)
- ✅ All dependencies auto-installed
- ✅ Sample problems ready to test
- ✅ Python API access

## Features in Colab

1. **Web Interface**: Gradio interface with public URL
2. **LaTeX Rendering**: Mathematical expressions rendered beautifully
3. **Error Classification**: Detailed error analysis
4. **Batch Processing**: Verify multiple answers at once
5. **API Access**: Use programmatically in cells

## Advantages of Colab Version

- ✅ No local setup needed
- ✅ Public URL (share with others)
- ✅ Free GPU/CPU resources
- ✅ All dependencies handled automatically
- ✅ Easy to share and collaborate

## Usage

After running all cells:

1. The Gradio interface will appear below the last cell
2. You'll get a public URL (e.g., `https://xxxxx.gradio.live`)
3. Share this URL with anyone to use the interface
4. Or use the embedded interface directly in Colab

## Troubleshooting

If something doesn't work:
1. Restart runtime: "Runtime" → "Restart runtime"
2. Run all cells again
3. Check for error messages in cells
